## 발전 우선순위

1. **하차 후 이어보기**: QR/링크로 장소 순서·주차 위치를 휴대폰에 전달. 현재 차량 화면만으로는 차를 떠난 뒤 코스를 보며 이동하기 어렵다.
2. **실제로 쓸 수 있는 주차장**: 주차장 입구·운영시간·방문객 조건·요금·데이터 기준시각 표시. 혼잡도 예측 정확도를 측정하고 실시간 값과 분리.

4. **심사 근거 강화**: 동일 목적지의 기존 수동 탐색과 비교해 조작 횟수, 코스 결정 시간, 목적지 누락률, 주차장 이용 불가율을 측정. 현재 MAU·리텐션은 가정이며 실측으로 표현하지 않기.

## Windows 재현 환경

한글 경로의 Gradle 테스트 프로세스·AAPT 실행 문제를 확인했다. 프로젝트는 P: 가상 드라이브, Gradle 캐시·임시는 C:/Android 아래 영문 경로를 사용하고 local.properties의 SDK 경로는 `sdk.dir=C\:/Android/Sdk`로 설정했다. API 키는 유지했다.

빌드 성공 메시지만으로 제출하지 않는다. `apksigner verify`, APK 내 AndroidManifest.xml 확인, Pleos에 `adb install -r -g` 성공을 반드시 함께 확인한다. 빌드 도구 버전 임의 대체 중 Manifest가 없는 APK가 만들어진 사례를 이번 검증에서 발견했다.
