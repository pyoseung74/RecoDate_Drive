# API 키 발급 안내

키는 `RecoDate_Pleos/local.properties`에 넣는다. 이 파일은 git에 올라가지 않는다.
키가 없으면 앱은 강릉 데모 데이터로 동작한다. 키를 넣은 뒤에는 다시 빌드해야 반영된다.

```
TMAP_APP_KEY=발급받은_앱키
DATA_GO_KR_KEY=공공데이터포털_일반인증키(Decoding)
```

## 1. TMAP 앱키 (장소 검색, 실시간 교통 경로)

1. https://openapi.sk.com 에 가입하고 로그인한다.
2. 마이페이지에서 **앱 만들기**를 누른다. 이름 예시: RecoDate Drive.
3. 만든 앱의 상품 목록에서 **TMAP**(API)을 선택해 사용 신청한다. 무료 체험 요금제를 쓴다.
4. 앱 상세 화면의 **App Key**를 복사해 `TMAP_APP_KEY`에 넣는다.

앱에서 쓰는 API:

- 주변 POI 검색: 음식점, 카페, 공원, 관광명소, 문화시설, 주차장, 전기차충전소, 주유소
- 자동차 경로안내 (`trafficInfo=Y`, 실시간 교통 반영)

### 무료 한도 보호 (필수 원칙: 무료 한도를 절대 넘기지 않는다)

공식 사이트에서 확인된 문구는 "POI 검색 일 2만 건, 경로탐색 일 1천 건 무료"뿐이다.
API별 정확한 한도, 월 한도, 초과 시 과금 여부는 확인되지 않았다. 그래서 앱이 두 겹으로 막는다 (`TmapQuota`).

| | 하루 상한 (기본) | 한 달 상한 |
|---|---|---|
| POI 검색 | 2,000건 (공개 수치의 10%) | 20,000건 |
| 경로 | 100건 (공개 수치의 10%) | 1,000건 |

- 호출 **전에** 1건을 차감한다. 상한에 닿으면 TMAP을 부르지 않고 예상값·데모 데이터로 대신한다.
- 한 달 상한을 공개 "하루" 수치로 잡아서, 무료 한도가 실제로는 월 단위여도 넘지 않는다.
- 키가 거부되면(401/403) 30분 동안 TMAP을 부르지 않는다.
- 같은 지역 POI 결과는 30분, 경로는 10분 캐시한다.
- 하루 상한은 `local.properties`에서 더 낮출 수 있다: `TMAP_DAILY_POI_LIMIT=500`, `TMAP_DAILY_ROUTE_LIMIT=30`
  (공개 수치의 80%보다 높게는 올라가지 않는다.)
- 사용량은 앱의 시연 패널(오른쪽 위 아이콘)에서 볼 수 있다.

**주의: 앱의 카운터는 기기마다 따로 센다.** 같은 키를 에뮬레이터, 실제 차량, 다른 PC에서 함께 쓰면 합계는 앱이 알 수 없다.
반드시 TMAP 대시보드(https://openapi.sk.com/mypage/dashboard)에서 **사용 제한량**을 무료 한도 이하로 설정해 둘 것.
이것이 서버 쪽에서 과금을 막는 유일한 확실한 방법이다.

추천 1번에 쓰는 호출 수:

- POI 검색: 6~7건 (장소 종류 5~6개 + 주차장 1개). 30분 안에 같은 지역을 다시 찾으면 0건
- 경로: 최대 3건

### 403 INVALID_API_KEY가 나올 때

- openapi.sk.com의 내 앱에서 **TMAP 상품(무료 요금제)을 사용 신청**했는지 확인한다.
- App Key를 다시 복사한다 (앞뒤 공백 주의). 따옴표는 있어도 된다.

## 2. 공공데이터포털 인증키 (기상청 날씨)

1. https://www.data.go.kr 에 가입하고 로그인한다.
2. **기상청_단기예보 ((구)_동네예보) 조회서비스**를 검색해 활용 신청한다. 자동 승인된다.
3. 마이페이지 > 개발계정에서 **일반 인증키 (Decoding)**를 복사해 `DATA_GO_KR_KEY`에 넣는다.
4. 승인 직후에는 키가 동작하기까지 1~2시간 걸릴 수 있다.
   그동안은 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(등록되지 않은 서비스키)가 나온다.
   몇 시간이 지나도 같으면 기상청 단기예보 서비스를 활용 신청했는지 확인한다.
5. Encoding 키(%2F 등이 들어 있는 키)를 넣어도 된다. 앱이 알아서 처리한다.

같은 키로 나중에 주차 관련 공공데이터(예: 전국주차장정보표준데이터, 실시간 주차정보)도 신청해 쓸 수 있다.

## 3. Pleos Playground (선택)

- Vehicle SDK와 NaviHelper SDK는 신청 없이 쓸 수 있다. 이 앱은 이 두 SDK만 쓴다.
- TTS, STT, FusedLocation은 아직 "준비 중"이다. 열리면 https://pleos.ai/playground 의 My Project에서 신청한다.
